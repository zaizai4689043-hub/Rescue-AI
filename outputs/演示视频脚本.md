## 1. 录制规格

| 项 | 规格 |
|---|---|
| 分辨率 / 帧率 | 1920×1080（导出基准）；录制源建议 2560×1600 或 2x Retina 缩放后下采样，**60fps**；慢速滚动镜头保持 60fps 防抖帧 |
| 浏览器 | Chrome 最新稳定版，**无痕窗口**（避免扩展注入与历史记录干扰）；缩放 100%；隐藏书签栏、隐藏下载/头像按钮，仅保留地址栏 |
| 窗口设置 | 浏览器全屏（⌘⌃F），录制前清空其他桌面通知、关闭消息弹窗；系统切深色外观（页面为深色主题，避免白边穿帮） |
| 控制台 | 全程**不打开 DevTools**；如需展示网络请求（异常桥段），另开一台窗口/画中画录终端 `curl` 输出，不在主画面开 Console |
| 密钥模式 | **真 AI 为主**（`http://localhost:8010/`，`backend/.env` 的 DASHSCOPE_API_KEY 可用）；异常处理桥段切 `?sim=1`；效果验证桥段用 `?replay=1`。三模式分别录满素材再剪 |
| 录屏工具 | 首选 **OBS**（macOS 屏幕采集，CRF 18、60fps、单独音轨）；备选 Screen Studio（自动变焦，适合 90 秒精简版）或 QuickTime + 后期剪辑 |
| 收音 | 独立麦克风录旁白干声（先录旁白、按旁白节奏剪画面，避免现场口播吃螺丝）；环境噪声 < -50dB |
| 字幕 | **全程硬字幕**（底部安全区，思源黑体/苹方，≥28px）；口径数字出现时同步打数字强调字幕；双语可选（评委版中文为主） |
| 录制顺序 | ① 重演剧场（`?replay=1`）素材 → ② 主模式第二幕素材 → ③ `?sim=1` 素材 → ④ 宕机/断网桥段（每条单独录，失败可重来）→ ⑤ 终端特写（pkill / curl） |

## 4. 风险与兜底

### 4.1 现场录崩处置

| 事故 | 处置 |
|---|---|
| 真 AI 超时 / 额度异常 | 该镜重录一次；再失败即切 `?sim=1` 录同机位同操作，角标如实打「离线兜底模式」——兜底本身就是演示内容，不用藏 |
| 代理崩溃 | `pkill -f ai_proxy.py` → `cd "backend/Qwen 初版" && python3 ai_proxy.py` → 刷新；断网期间页面自动降级不崩 |
| 简报出稿超 5s | 走预热缓存秒回重录；口径镜头（S09）改用静帧 + 字幕，不依赖实时生成 |
| 换图重判命中缓存同值 | 等满 60s 代理缓存过期再录，或换一张未研判过的真实照片 |
