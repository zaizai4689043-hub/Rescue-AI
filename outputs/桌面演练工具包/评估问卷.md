# 桌面演练评估问卷

> 所属：RescueAI 桌面演练工具包（WP12）｜ 填写人：指挥员（受邀真实应急人员）
> 说明：本问卷用于评估 RescueAI 作为**辅助决策工具**的可用性；系统仅提供建议，不承担任何行动指令职能。您的判断即演练结论，请如实填写。

## 第一部分：量表题（1–5 分）

> 1 = 完全不同意 / 很差，2 = 不太同意，3 = 一般，4 = 比较同意，5 = 完全同意 / 很好。

| # | 维度 | 题目 | 评分（1–5） |
|---|---|---|---|
| 1 | 辅助决策价值 | 该系统提供的优先级排序，对我判断资源投放顺序有参考价值 | |
| 2 | 辅助决策价值 | AI 简报/决策理由整理信息的方式，比我自己逐条浏览社媒更快 | |
| 3 | 辅助决策价值 | 我愿意在真实应急场景中将此类系统作为辅助工具使用 | |
| 4 | 信息时效感知 | 系统聚合社情与官方通报的速度，符合我在震后早期决策时的时效预期 | |
| 5 | 信息时效感知 | 「官方通报滞后期由 AI 简报补位」的做法，在真实指挥流程中对我有用 | |
| 6 | 定位可信度 | 系统给出的地点定位与热力分布，我清楚它是怎么来的、可信到什么程度（系统已说明：地名为词典定位，置信度 0.85 / 回退 0.4，定位准确率不作承诺） | |
| 7 | 定位可信度 | 标注了依据与置信度的定位结果，我敢于将其作为研判的参考之一 | |
| 8 | 误报控制感知 | 系统对社情的过滤（去重、辟谣、机器人识别、地理范围限定）有效减少了干扰信息 | |
| 9 | 误报控制感知 | 无社情匹配的区域如实显示「社情信号 ×0 · 依据官方通报」而不编造，这种处理方式令我信任 | |
| 10 | 责任边界清晰度 | 系统各处提示「建议供参考、最终决定权在现场指挥部」，边界清晰、不会让我误以为系统在下达指令 | |
| 11 | 责任边界清晰度 | 派遣前的二次确认与「上报现场指挥部」流程，符合真实指挥中的决策习惯 | |
| 12 | 整体信任度 | 综合本次演练，我信任该系统输出结果的整体可靠程度 | |
