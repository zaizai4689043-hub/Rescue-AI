# v4.0 — 平台化并轨

> 决赛后启动的产品化版本。目标: 演示线 9 项已验证能力全量迁入标准平台，视觉切换到 v3.0 体系，单文件版归档为"离线应急包"。

## 核心目标

1. **能力并轨**: 演示线 8 项 AI 能力（双源感知、简报、优先级、热力图、空中搜索、余震联动、历史回测、三级降级）全部迁入 `backend/app/`
2. **视觉升级**: Element Plus → Tailwind，品牌色 / Design Tokens / 深浅色双主题 落地
3. **导航精简**: 11 视图 → 5 模块
4. **流程提速**: 灾情上报 7 步 → 3 步
5. **AI 集成**: AIRecommendation 模型、AI 调度建议卡、定时日报
