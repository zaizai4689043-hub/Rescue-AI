# RescueAI 版本库索引

> 本目录归档 RescueAI 项目历次迭代的关键产物（规划文档、设计系统、交付物、截图证据），用于沉淀版本基线、回溯决策轨迹与答辩材料归档。
> **原则**: 只归档"已完成该版本职责"的静态产物；仍在开发中的工作副本留在根目录对应位置。

## 目录结构

```
│

│   ├── README.md                             版本快照说明

```

## 使用方式

- **查阅历史**: 直接浏览对应 `versions/vX.Y/` 子目录
- **版本交接**: 每完成一个里程碑，将对应版本的工作产物复制到本目录，并更新该版本 `README.md`
- **当前工作副本**: 始终位于根目录对应位置（`documents/`、`frontend/`、`backend/`、`deploy/`、`outputs/`、`screenshots/`）
- **Git 基线**: 每次版本归档应伴随一次 git commit，标签形式建议 `vX.Y-baseline`

## 与根目录的关系

| 位置 | 角色 |
|------|------|
| `documents/` | **工作文档**（当前迭代活跃） |
| `outputs/` | **工作产物**（当前迭代产出） |
| `screenshots/` | **工作截图**（当前迭代采集） |
| `versions/vX.Y/` | **版本归档**（里程碑产物快照） |

归档 ≠ 删除。归档是版本产物的**快照备份**，原位置保留工作副本。
