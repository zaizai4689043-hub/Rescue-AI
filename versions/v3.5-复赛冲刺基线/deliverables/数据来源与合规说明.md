## 一、文档目的与适用范围

本文档说明 RescueAI 项目在研发、演示与参赛过程中所使用的全部数据的**来源、授权状态、脱敏处理方式与合规边界**，供赛事评审核查数据来源合法性与合规性。

适用范围：

- RescueAI 指挥中心演示版（单文件 HTML 演示程序及本地代理）；
- 历史重演剧场、双源灾情感知、社情瀑布流与灾情热力图等演示模块所引用的数据；
- 本交付包内随附的数据产物文件。

本文档不覆盖任何真实救援行动中的实时数据接入；实时数据接入方案（规划中）见第三章第 4 节，以官方渠道授权为前提。

## 三、授权状态（逐项说明）

1. **学术公开数据集（社情语料）**：该数据集以公开研究用途发布，本项目按其公开研究用途使用，并在此基础上执行了更严格的脱敏处理与使用限定——**仅用于演示展示，不用于任何模型训练，不进行二次分发**。
2. **政府与国际机构公开数据（CENC / USGS / ICL 等）**：均为公开发布的震情与预警数据，本项目以引用方式使用，在演示界面与文档中注明来源机构，遵守各机构公开数据的引用规范；不对原始数据做任何修改性再发布。
3. **官方通报与公开报道**：伤亡阶梯、救援锚点等事实均摘自新华社、央视、应急管理部、WHO 等官方公开通报与报道，仅作事实性引用并注明出处。
4. **官方商业通道（实时社情，体验期已联调）**：以微博开放平台官方渠道（weibo-cli / 官方商业 API）的**订阅与合同授权为准**。当前状态（2026-08-28 实测）：

   - 已领取 **7 天免费体验包**，服务状态 `trial_active`，**有效期至 2026-09-04**，体验期内检索调用**零积分消耗**；

## 四、脱敏方式

### 4.1 历史社情数据的脱敏管线（已实施，自动校验）

对学术数据集的 53,340 条原始微博，产出演示产物前逐条执行以下脱敏处理：

| 步骤 | 处理方式 |
|---|---|
| 1. 发布者身份整列丢弃 | 原始数据的**用户昵称列与数字 UID 列整列丢弃**，从源头消除身份标识 |
| 2. 正文社交引用剥离 | 正文中的 **@提及、t.cn 短链、用户主页链接全部剥离** |
| 3. 标识不可逆化 | 输出中 `post_id` 为原始文本 ID 的**不可逆哈希**（`wb-` 前缀），无法反查原始帖文与用户 |
| 4. 自动合规校验 | 产出前自动校验：无数字 UID 模式、无 @提及、无短链；不通过即拦截 |
| 5. 使用限定 | 产物**仅用于演示展示，不用于训练或二次分发** |

上述管线一键生成、幂等可复现，处理逻辑与产物结构在 `backend/Qwen 初版/data/README.md` 中有完整记录。

### 4.2 实时接入隐私设计（已随官方通道联调落地）

经微博开放平台官方渠道（weibo-cli）接入实时社情数据时，执行与历史语料同一隐私标准：

- **不保留发布者昵称与 UID**，仅保留文本内容与发布时间；
- 接入前经同样的脱敏与合规校验管线；
- 仅经微博开放平台官方通道获取，不采集官方通道以外的任何数据。

## 五、隐私保护

1. **不采集真实个人信息**：本项目不采集、不存储任何真实用户的个人信息；历史语料的发布者身份信息（昵称、UID）已在脱敏管线中整列丢弃。
2. **不追踪用户**：系统不对任何微博用户或其他个体进行追踪、画像或行为分析；演示产物中的 `post_id` 为不可逆哈希，不具备反查能力。
3. **演示数据不含可识别个人身份字段**：52 条精选产物仅包含匿名化正文、时间、抽取地名、损毁类型等灾情相关字段，经自动合规校验确认不含数字 UID、@提及与用户链接。
4. 涉及真实伤亡与获救案例的展示内容，均取自官方通报与公开报道，采用致哀基调与克制表述，不渲染、不扩散个体细节。

## 六、行业风险提示

社媒灾情信息天然存在以下风险，本项目在产品层面已做对应设计，使用者仍需知悉：

1. **信息质量风险**：社媒内容可能包含**谣言、夸大、重复与情绪化转发**（原始数据集中 25.2% 为「愿平安」类情绪转发；存在营销号提前挂热点词条的异常数据），且存在**幸存者偏差**——能发声者不代表受灾全貌。对此，系统设计了去重、辟谣、机器人识别、地理围栏四层过滤管线，并要求**社情信号与官方通报交叉验证**：无社情匹配的区域如实显示「社情信号 ×0 · 依据官方通报」，不编造。
2. **模型推断的不确定性**：灾情热力图、区域优先级与被困规模预估均为**模型推断结果**，存在不确定性；系统对所有预测展示依据与置信度（如地名抽取未命中时回退震中坐标并降低置信度），不作为唯一决策依据。
3. **数据时效与覆盖范围限制**：实时社情的时效与覆盖面受**平台授权范围**限制；历史重演所用数据集以中文微博为主，不代表灾区全部语种与渠道的信息全貌。

---

## 七、不可替代专业决策的边界

1. RescueAI 是**辅助决策系统，不替代专业救援判断**。系统输出的一切简报、评分、优先级与建议，均为辅助参考信息。
2. **一切救援行动以现场指挥部与专业救援力量的判断为准**；系统不承担任何行动指令职能。
3. **伤亡人数、震级等关键数字以官方通报为权威口径**。本项目固定口径为：
   - 震级：**CENC 中国地震台网 7.9 级 / USGS Mw 7.7**（双口径并列，引用须注明来源）；
   - 死亡人数：**截至 3/29 晚通报 1,644 人**，持续更新中；
   - 社媒响应特征：震后**约 5 分钟**社交媒体上已流传伤亡数字（官方首报约 5 小时后）；**首条涉震微博早于主震发震时刻 1 分 46 秒**——社媒是最快的「第一传感器」，但其数字不可直接作为通报口径。
4. 演示中的伤亡数字均采用「以下数字来自官方通报，谨以致哀」的致哀口径；沙盘推演中的被困者为数字孪生推演样本，与真实数据边界清晰标注。

## 九、合规承诺与联系方式

### 合规承诺

1. 本项目所有数据来源合法、授权明确：**学术数据集按公开研究用途使用且仅演示不训练不分发；政府与国际机构数据公开引用并注明来源；官方商业通道已通过开发者认证并领取体验包（有效期至 2026-09-04），长期接入以正式订阅/合同授权为准**。
2. **不自建爬虫采集社媒数据，不使用无官方背书的第三方聚合接口**；实时接入仅通过微博开放平台官方通道，当前为官方体验期内的合规试用，到期后自动降级。
3. 所有社情数据经昵称/UID 整列丢弃、社交引用剥离、标识不可逆哈希的脱敏管线处理，并通过自动合规校验。
4. 不采集真实个人信息、不追踪用户；关键灾情数字以官方通报为权威口径；系统定位为辅助决策，不替代专业救援判断。
5. 如赛事主办方或数据来源方提出进一步合规要求，项目组将立即配合整改。

### 联系方式

联系方式以赛事报名表为准；如需对外公布，由参赛团队于提交前补充。
