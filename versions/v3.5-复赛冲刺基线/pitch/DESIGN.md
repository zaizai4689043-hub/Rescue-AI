# DESIGN.md — RescueAI 黑客松路演 PPT 设计稿

## 场景判定

黑客松产品路演 → 走通用设计原则（universal-only）。品牌沿用 RescueAI 产品暗色指挥中心视觉：深海军蓝底 + 琥珀警示 + 青色科技。

## 1. 画布与母版

画布 1280×720。默认母版三区：

| 区 | 垂直位置 | 高度 | 规则 |
|---|---|---|---|
| A · 标题块 | 0–120px | 120px（上 padding 20） | 主标题 34px bold，左侧；下方 3px 琥珀→青渐变短条（宽 64px） |
| B · 内容区 | 120–660px | 540px | 正文/图表/配图 |
| C · 页脚条 | 660–720px | 60px（下 padding 20） | 左 "RescueAI · Physical AI for Earthquake Rescue" 14px 灰；右页码 NN / 10 |
| padding | 上下 20、左右 64 | — | — |

封面(P1)/三问(P3)/结束页(P10) 用自定义版式，可省略 C 区。

## 2. 颜色系统（4 hex）

| 角色 | hex | 用途 |
|---|---|---|
| 主色（背景） | `#0F172A` | 全篇背景、大色块 |
| 辅色 | `#22D3EE` | 科技/AI 元素、图表第二系列、链接色、卡片描边 |
| 强调色 | `#F59E0B` | 呼救/优先级/核心数字/警示焦点，只出现在焦点元素 |
| 文本色 | `#F1F5F9` | 标题/正文（次级文本用其 60% 透明度） |

辅助中性色（不计入 4 hex 配额，仅作层次）：`rgba(148,163,184,0.5)` 次级文字、`rgba(30,41,59,0.8)` 卡片底、`rgba(34,211,238,0.15)` 青色半透底。

**渐变方案**：标题下短条 `linear-gradient(90deg, #F59E0B, #22D3EE)`；封面蒙版 `linear-gradient(90deg, rgba(15,23,42,0.92) 30%, rgba(15,23,42,0.35) 100%)`；P0-P3 条带 `#EF4444→#F97316→#F59E0B→#64748B` 单色序列（P0 红仅出现在优先级条内，属语义色）。
**半透明策略**：卡片底 `rgba(30,41,59,0.55)` + 1px `rgba(34,211,238,0.25)` 描边；背景网格 SVG `opacity: 0.05`。

**每页色彩分配**：

| 页 | 分配 | 说明 |
|---|---|---|
| P1 | 主色 55% + 辅色 25% + 强调 15% | hero，强调色给标题关键词 |
| P2 | 主色 60% + 辅色 20% + 强调 12% | 数字锚点用强调色 |
| P3 | 主色 62% + 强调 18% | hero，三问大字 |
| P4 | 主色 65% + 辅色 25% + 强调 5% | transition 克制 |
| P5 | 主色 60% + 辅色 28% + 强调 6% | 地图热力点含语义红橙 |
| P6 | 主色 62% + 辅色 22% + 强调 10% | P0-P3 条带 |
| P7 | 主色 50% + 辅色 25% + 强调 8% | 大图页 |
| P8 | 主色 65% + 辅色 25% + 强调 4% | 架构页克制 |
| P9 | 主色 58% + 辅色 18% + 强调 14% | 数字锚点页 |
| P10 | 主色 60% + 强调 16% | hero 金句 |

## 3. 字体系统

- 中文：思源黑体（Source Han Sans SC）；西文/数字：JetBrains Mono（数字与芯片标签）/ Space Grotesk（大标题西文）。

| 层级 | 字号 | 字重 | 行高 |
|---|---|---|---|
| 封面主标题 | 56px | bold | 1.25 |
| 章节/金句大字 | 44–64px | bold | 1.2 |
| 巨型数字锚点 | 72–110px | bold (JetBrains Mono) | 1.0 |
| 页面主标题 | 34px | bold | 1.3 |
| 卡片小标题 | 22px | 600 | 1.35 |
| 正文 | 18–20px | regular | 1.55 |
| 脚注/页码 | 14px | regular | 1.4 |

## 4. 信息密度与留白

常规内容页留白 ≤ 35%；P1/P3/P10 为 hero/金句页，留白 38-42%（围绕焦点元素）。内容页正文字数 ≥ 180（P5/P6/P8 达标），卡片组每卡 ≥ 60 字。容器填充率 ≥ 85%，卡片尾部元素 marginTop:auto 锚底。

## 5. 配图系统

| 等级 | 文件 | 位置 | 占比 |
|---|---|---|---|
| L1 | cover_hero.png | P1 全幅铺底 | B 区 100% |
| L1 | drone_hero.png | P7 左栏铺底 | B 区 55% 宽 |
| L3 | 品牌盾形标（SVG） | C 区左侧 | 全篇一致 ≤ 40×40 |

SVG 适用范围：灾情地图/热力点、七步链路、P0-P3 条带、四层架构、时间线、递减条、背景网格——结构化元素全部 SVG。生图风格统一：**暗色电影感、深蓝调、琥珀+青色光效点缀、写实摄影风**，两图同风格。
