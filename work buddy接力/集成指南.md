## 三、数据导入

### 导入缅甸地震微博数据

将 `backend/Qwen 初版/data/social_posts.json` 导入新系统：

```python
import json
from services.weibo_pipeline import weibo_pipeline

with open("backend/Qwen 初版/data/social_posts.json", "r") as f:
    posts = json.load(f)

# 转换格式并批量导入
batch = []
for post in posts:
    batch.append({
        "text": post["text"],
        "published_at": post["time"],
        "offset_min": post.get("offset_after_quake_min"),
    })

result = weibo_pipeline.batch_ingest(db, batch)
print(result)  # {'ingested': 45, 'filtered': 5, ...}
```
