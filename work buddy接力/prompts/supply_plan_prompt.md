# 物资投送规划提示词

## 使用场景
根据灾情热点优先级和无人机载重能力，AI 推荐最优物资投送方案。

## 提示词

```
你是应急救援物资调度专家。根据灾情热点信息，推荐最优无人机物资投送方案。

灾情热点信息：
{hotspot_data}

可用无人机：
{available_drones}

物资分类参考：
- shelter: 帐篷/折叠床/棉被/防水布/取暖炉
- food: 压缩饼干/方便面/自热米饭/矿泉水/婴幼儿食品
- medical: 急救包/止血带/夹板/消炎药/破伤风疫苗/氧气袋
- water: 瓶装水/净水片/蓄水袋
- lighting: 手电筒/应急灯/发电机/燃油
- communication: 对讲机/卫星电话/充电宝
- rescue_tool: 液压钳/生命探测仪/破拆工具/支撑杆

请返回严格 JSON：
{
  "recommended_package": "物资包名称",
  "manifest": [
    {
      "item": "物资名",
      "qty": 数量,
      "weight_kg": 单件重量,
      "category": "分类"
    }
  ],
  "total_weight_kg": 总重,
  "drone_assignment": "推荐的无人机编号",
  "rationale": "方案理由（100字内）",
  "drop_method": "hover_drop|land|parachute",
  "drop_altitude_m": 投送高度
}
只返回 JSON。
```

## 标准物资包（降级用）

| 优先级 | 包名 | 核心物资 | 适用场景 |
|--------|------|----------|----------|
| P0 | 紧急生命救援包 | 急救包×10、生命探测仪×2、水×24、压缩饼干×20 | 有被困人员、需立即救援 |
| P1 | 基本生存保障包 | 帐篷×5、水×48、方便面×30、急救包×5、手电筒×10 | 灾民转移、临时安置 |
| P2 | 生活保障补充包 | 棉被×20、矿泉水×48、自热米饭×30、对讲机×5 | 安置点运行、通信恢复 |
| P3 | 恢复重建支持包 | 防水布×20、发电机×2、净水片×100 | 灾后恢复、长期保障 |

## 载重约束
- 大疆 M300 RTK: 最大载重 2.7kg
- 大疆 M350 RTK: 最大载重 5.0kg
- 翼龙-2H: 不载货（通信中继型）

## 投送方式选择
- `hover_drop`: 悬停投放（默认，5m 高度）—— 适用于开阔场地
- `land`: 降落卸货 —— 适用于有平坦起降点的区域
- `parachute`: 降落伞投送 —— 适用于无法悬停或高空投放

## 降级规则
- AI 不可用时，按热点优先级使用标准物资包
- 载重超标时，拆分为多次投送
- 无可用无人机时，加入待队列等待
